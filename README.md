# 🧠 Mind Bridge

*A mental wellness platform that bridges the gap between individuals seeking psychological support and licensed mental health professionals.*

---

## 📖 About the Project

Mental health challenges often go unseen, yet they can have a significant impact on people's lives. Many individuals struggle to access professional support due to limited availability, communication barriers, or simply not knowing where to begin.

**Mind Bridge** was created to simplify that journey. The platform connects users with licensed psychologists and psychiatrists through a clean, organized, and user-friendly experience. It helps users move from uncertainty to support by making professional mental health services easier to discover and access.

---

## ✨ Key Features

### 👤 For Users

* Browse verified mental health professionals
* View detailed professional profiles, including:

  * Biography
  * Specialization
  * Languages spoken
* Check weekly availability
* Send consultation requests
* Track request status:

  * ⏳ Pending
  * ✅ Accepted
  * ❌ Declined

### 🩺 For Professionals

* Secure authentication (Sign Up / Log In)
* Create and edit professional profiles
* Manage incoming consultation requests
* Accept or decline consultation requests
* Set and update weekly availability schedules

## 🔄 System Flow

1. User creates an account or logs in.
2. User browses available mental health professionals.
3. User views a professional's profile.
4. User submits a consultation request.
5. The professional receives the request.
6. The professional accepts or declines the request.
7. The user receives the updated consultation status.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Melala-9716/mind-bridge.git
cd mind-bridge
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env.local` file in the project's root directory and add the following:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```
